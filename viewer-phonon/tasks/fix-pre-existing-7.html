tests/test_karplus_strong_damping is PRE-EXISTING flaky (verified: fails ~7/20 on unmodified main, ~1/20 on the noise-RNG branch — same statistical design flaw, NOT caused by wave3-noise-rng-hotpath). It renders TWO independent Karplus-Strong plucks with different random pluck excitations (pluck 440 0.1 vs pluck 440 0.9) and asserts the high-damping late-RMS < low-damping late-RMS. Because each pluck seeds its delay line from an independent random excitation, ~35% of realizations tip the comparison.

Discovered while implementing wave3-noise-rng-hotpath.

File scope: tests/test_karplus_strong.rs ONLY. Implement directly — do not decompose.

Fix options (pick the robust one):

  • Average late-RMS over N (e.g. 8) independent renders per damping to wash out excitation variance, OR
  • Assert on the decay-rate ratio with a tolerance calibrated so it is green across ≥50 consecutive runs.

Validation
