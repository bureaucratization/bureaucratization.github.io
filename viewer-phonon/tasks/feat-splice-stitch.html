## Description
Add two commonly-reached Tidal sampler/combinator ops that are still missing:
- **splice** — like `slice` but adjusts playback speed so each slice fills its event
  duration (beat-locked slicing). Only `slice`/`striate`/`chop`/`bite`/`chew` exist today.
- **stitch** — boolean pattern interleaves two value patterns (the complement of `sew`,
  which IS wired at compositional_compiler.rs:2516). `stitch` is a known keyword
  (compositional_compiler.rs:642) but has no `compile_stitch`.

**File scope:** `src/compositional_compiler.rs` (add `Transform::Splice` execution +
register `splice`; add `compile_stitch` mirroring `compile_sew`) +
`src/pattern_ops_extended.rs` (the `splice`/`stitch` pattern implementations) + tests.
Serial after `feat-chord-support` (same `compositional_compiler.rs`). Implement directly.
