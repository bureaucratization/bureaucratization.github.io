Description

Extend the existing glitch harness (see extend-glitch-harness / audio-live-edit-glitch-harness in git log) into a comprehensive headless stress harness that simulates an interactive live-coding session end-to-end: load a DSL program, render continuously, and perform scripted AND seeded-random sequences of graph swaps, edits, and tempo changes while analyzing output for defects.

Read docs/audits/test-gap-analysis-2026-07.md and docs/audits/live-transition-2026-07.md FIRST and make sure the harness covers the failure scenarios they identify.

Requirements:

  • Drives the REAL swap code path used by phonon-edit, not a parallel test-only path
  • Defect detectors: clicks/discontinuities (sample-delta threshold), dropouts/unexpected silence, NaN/inf, DC offset, stuck voices, unbounded RMS growth, callback-budget overruns
  • Deterministic seeded mode; any failing sequence reproducible from its seed; runnable in CI with a single cargo command
  • TDD: write failing detector self-tests first against synthetic audio with injected defects, then integrate

If the harness finds real defects, file each one as a new wg task with its reproduction seed and a ## Validation section — do not fix them in this task.

Validation

  • Single cargo command runs the harness with a --seed parameter
  • Self-test proves detectors catch injected click, dropout, and NaN defects
  • A seeded randomized session of >= 60s-equivalent audio with >= 50 graph swaps completes with zero false positives on known-good programs
  • Failure scenarios from both audit reports are represented in the scripted scenario set
  • Real defects found are filed as wg tasks with reproduction seeds
