Description

Addresses C1 (rt-safety audit F-1; test-gap RC-1/G-1/P0-A; live-transition R1/R2). The reload thread holds try_borrow_mut() on the OLD graph across transfer_* while the synth thread does an unconditional borrow_mut() on the same ArcSwap-shared GraphCell → RefCell double-borrow → panic → synth thread dies → ring drains → audio stops permanently. This is a fresh partial regression from the reload-continuity fixes, on the two most-used surfaces (phonon live, phonon-audio). The modal editor is already safe (src/modal_editor/mod.rs:280,314 uses try_borrow_mut()+skip); this task ports that pattern to the product surfaces.

See docs/audits/rt-safety-2026-07.md §4 F-1 and docs/audits/improvement-plan-2026-07.md C1.

Scope / Constraints

  • Files: src/main.rs (synth loop :1006), src/bin/phonon-audio.rs (synth :288). Do NOT touch src/unified_graph.rs (owned by the serial chain) — this is a pure caller-side change.
  • Mirror the modal editor exactly: synth thread uses try_borrow_mut() and skips on Err (write nothing that iteration), never borrow_mut().unwrap().
  • This is the SYMPTOM fix (stops the panic). The underlying data race on the non-atomic RefCell borrow flag is the deferred render-owner refactor (see plan §5) — do not attempt the threading rewrite here.
  • Implement directly — do not decompose further.

Reproduction (interactive → stress harness)

The defect is interactive (edit-while-playing). Extend the stress harness concurrent session to drive the phonon live / phonon-audio swap path (currently it exercises the modal path). A tight synth-render loop + a reload thread issuing swaps must reproduce the borrow_mut panic (synth thread death) on main.

Validation

  • Failing test first: a concurrent stress-harness regression (real synth thread + reload thread) targeting the product-surface swap discipline that reproduces the synth-thread panic / permanent-silence on main (assert synth_thread_alive == false or a caught panic pre-fix).
  • Fix: synth threads in src/main.rs and src/bin/phonon-audio.rs use try_borrow_mut()+skip-on-Err.
  • Post-fix: the concurrent regression stays green across a bounded N-swap run (synth_thread_alive, nonfinite_in_output == 0, no permanent silence); cargo run --release --bin glitch_stress -- --seed 42 --concurrent exits 0.
  • cargo build + cargo test pass with no regressions.
