Description

Addresses G5 (rt F-6) and folds in I1 (test-gap P0-C), which are two sides of the same coin.

  • G5 / F-6: the global output guard (src/unified_graph.rs:7719-7724) stops NaN/Inf/denormal from reaching the ring, but if a resonant filter, FM feedback loop, delay/reverb, or plugin drives its internal state to NaN/Inf, the state persists: the output guard zeros the sample but the node keeps emitting NaN → the voice/bus is stuck silent until reload.
  • I1 / P0-C: because sanitisation runs BEFORE any test observes output, the stress/glitch harness NaN & clip gates are tautological (a NaN inside the graph reaches the harness as a clean 0.0). Any real test of F-6 REQUIRES observing the raw, pre-sanitisation signal.

See docs/audits/rt-safety-2026-07.md §4 F-6, docs/audits/test-gap-analysis-2026-07.md P0-C, and docs/audits/improvement-plan-2026-07.md G5/I1.

Scope / Constraints

  • Files: src/unified_graph.rs (+ src/stress_harness.rs + tests). Serial chain: --after harden-render-locks.
  • Add a debug/cfg-gated pre-sanitisation invariant hook sampled just before the Phase 4b-4d limiter/flush (unified_graph.rs:7706) recording raw non-finite count, raw peak (pre-limiter), raw max sample-to-sample delta, and the originating node id of the first non-finite sample. Wire it into the stress harness so scenarios assert on RAW metrics.
  • Sanitize stateful node state on write in the common eval helpers (filters, delays, feedback, oscillator phase) — flush non-finite internal state and reset the node to a safe state when its output is caught non-finite. Do not rely on the output guard alone.
  • Also promote the currently-dead DC-offset gate (test-gap G-7) to an assertion if practical.
  • Implement directly — do not decompose further.

Reproduction (interactive → stress harness, raw metrics)

A seeded NaN-producing graph (divide-by-zero node, or feedback blow-up) currently reaches the harness as clean 0.0 (silence). With the raw probe it must be caught pre-sanitisation, and after the fix the node must recover instead of going stuck-silent.

Validation

  • Failing test first: a stress-harness scenario with a seeded internal NaN (e.g. feedback blow-up) that (a) is caught at the raw pre-sanitisation probe even though sanitised output is 0.0, and (b) demonstrates the node stays stuck-silent on main.
  • Fix: sanitize/reset internal node state; the node recovers to producing finite audio after the transient (assert post-recovery RMS > 0 / raw non-finite returns to 0).
  • Post-fix: cargo run --release --bin glitch_stress -- --seed 42 exits 0 with raw-metric gates active (no longer tautological).
  • cargo build + cargo test pass with no regressions.
