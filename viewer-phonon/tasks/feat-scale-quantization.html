## Description

`~mel $ n "0 2 4 7" # scale "minor"` and `note "c e g"` / `n "c4 e4 g4"`.

scale-degree indices to semitone offsets; add note-name -> semitone parsing.

**File scope:** NEW `src/scale_dsl.rs` (degree->semitone + name->semitone maps, reusing the
`midi_input::Scale` table) + `src/compositional_compiler.rs` (register `scale`; extend the
