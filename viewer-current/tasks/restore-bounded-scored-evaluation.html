Description

Restore a real, bounded, scored evaluation authority now that the legacy evaluator mutation machinery was retired. wg evaluate run <done-task> must no longer be a dead CLI. Implement the smallest task-centric path: verify the task's receipt-backed terminal observation and immutable completion/publication evidence; resolve the exact configured evaluator Pi route/reasoning; execute one bounded read-only evaluator call; validate a structured 0..1 overall score plus bounded dimensions/notes; persist an immutable, exactly-once Agency evaluation through the existing Agency store/performance surfaces; and make repeated run/restart/reload idempotent. Evaluation observes Done and must never complete/fail/reopen/retry/publish a task or create evaluator graph nodes. Provider/setup failure is visible and neutral. Preserve wg evaluate record. Do not resurrect PendingEval, synthetic .evaluate-* tasks, auto-assignment brokers, or the deleted evaluator lifecycle. Correct CLI/help/docs that currently claim both that wg evaluate is the scoring authority and that it is retired. Use fake providers for automated tests; leave one explicit operator-run real-model canary command and bounded evidence.
