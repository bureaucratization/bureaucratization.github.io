## Objective
Implement the command-surface cutover in `docs/design-project-local-pi-config.md`.

Required behavior:
- `wg setup` and all ordinary config writes target `.wg/config.toml` by default; global mutation requires an explicit `--global` (or an equally explicit legacy compatibility form with a loud warning).
- `wg profile select` is the documented project-local operation and applies only the allowed route/reasoning/resource/archive profile keys without clearing existing local guardrails.

- Pi-only setup requires neither `~/.wg/config.toml`, `~/.wg/active-profile`, nor WG-managed provider credentials.
- Help, quickstart, errors, dry-run, and JSON output describe exact scope and winning source consistently.
