Validation

  • Real terminal/TUI flow from installation through first useful reviewed change is driven and recorded with no secret-bearing logs.
  • Missing login/route yields an actionable error; existing Pi auth is owned by Pi and no WG secrets are required.
  • Isolated project changes do not affect another project or operator global state.
  • Interruption/restart preserves candidate work and gives one truthful next action; no orphan owned processes remain after teardown.
  • Report distinguishes tests, semantic review, local landing, and remote publication; no future self-receipt is required as pre-review evidence.
  • Relevant tests and owned human-flow smoke checks pass; skipped/blocked steps are explicitly identified, never called passes.
