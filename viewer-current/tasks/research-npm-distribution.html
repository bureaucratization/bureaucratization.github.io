Research npm distribution for the WG Rust binaries (worksgood/wg/nex): produce a decision doc (docs/research/npm-distribution.md) covering the established patterns for shipping native binaries via npm — the esbuild/biome/rollup model: a small metapackage plus per-platform optionalDependencies (@worksgood-linux-x64-gnu, @worksgood-darwin-arm64, etc.) containing prebuilt binaries, zero postinstall scripts, version-locked to the metapackage. Cover: (1) how cargo build/release would produce and attach per-target binaries (CI matrix, glibc vs musl, macOS codesigning/notarization if relevant); (2) how the npm wrapper resolves and execs the right platform binary and falls back to a cargo-install hint; (3) interaction with the existing install path (cargo install --git stays supported; npm is additive) and with the pi npm package users already install; (4) versioning/sync between crates.io-style versioning and npm; (5) security posture (no postinstall, checksums, npm provenance/attestation); (6) effort estimate and a concrete recommendation with a milestone-sized first slice (e.g. linux-x64 + darwin-arm64 only).
