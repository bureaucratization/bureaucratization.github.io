Description

Objective

Narrow and harden the just-landed evaluation-cutover implementation so legacy synthetic .assign-*, .flip-*, and .evaluate-* rows cannot deadlock modern graphs, while preserving evidence and never inventing lifecycle acceptance.

The common upgraded-graph case must self-heal without graph surgery: when an ordinary source is already receipt-backed Done/Landed, the mere presence of a retired .evaluate-<source> row must not block downstream readiness even before an operator runs migration. Retired rows must remain excluded before priority inheritance/order/dispatch and must not produce per-tick spam. Explicit legacy edges through retired rows should resolve through the associated source semantics or be rewritten by the migration without weakening a non-Done source.

Keep wg migrate evaluation-cutover as an idempotent, backup-producing historical-marking/edge-normalization command, but remove or repair unsafe lifecycle inference added in d9834007:

  • do not treat an arbitrary content-addressed object as an acceptance receipt; any automatic PendingEval→Done conversion must parse and verify the typed receipt against task, generation, candidate, contract, disposition, and publication;
  • do not use caller-controlled WG_AGENT_ID presence/absence as operator authorization;
  • prefer leaving ambiguous PendingEval fail-closed with the already-supported explicit retry/recovery path rather than adding a weak --accept escape hatch;
  • restore unrelated reasoning migration and durable evaluation-verdict reconciliation phases accidentally removed from the coordinator tick.

Use the semantic rule: obsolete task rows have no authority; the source task's modern lifecycle/receipt state remains authoritative. Preserve all old rows/logs/verdict files byte-for-byte except for explicit migration metadata and documented edge rewrites.

Validation

  • Add a regression for the reported exact flow: source Done/Landed + stale non-Done .evaluate-source + downstream after = [source] dispatches without rm-dep, manual score, or required pre-migration mutation.
  • Add tests for explicit edges involving each retired row and for non-Done/PendingEval/Failed sources remaining fail-closed under source semantics.
  • Add typed receipt-binding negative tests using arbitrary CAS bytes, wrong task/generation/candidate/contract/disposition/publication, and stale receipts.
  • Prove worker-controlled environment variables cannot authorize adjudication; remove the escape hatch if no authenticated capability already exists.
  • Prove coordinator reasoning migration and durable verdict reconciliation still run, and retired rows never enter promotion/order/dispatch accounting.
  • Run the existing evaluation_cutover_migration smoke plus a terminal-level no-migration legacy-Done self-heal scenario registered in the grow-only manifest.
  • Run focused Rust tests and cargo fmt --check; capture exact evidence and report changed files/residual risks.
