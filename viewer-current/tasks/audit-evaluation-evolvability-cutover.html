Description

Perform a focused audit of the cutover from real .assign-*, .flip-*, and .evaluate-* graph satellites to lazy evaluation records and the worker-owned manifest-bound completion valve. Determine whether the new architecture preserved the useful properties of the old graph representation—interpretability, attribution, attempt history, model/usage/cost accounting, inspectable failures, assignment feedback, and agency evolution—while removing its known lifecycle hazards.

Reconstruct the historical and normative intent from Git history and the relevant designs, then verify the current production paths in source and this live graph. Keep these distinct: legacy agency evaluation files/performance propagation; candidate-bound EvaluationRecord bounded/deep lanes; synchronous completion FLIP/eval receipts created by wg submit; direct dispatcher assignment; and agency assigner/evolver behavior. Trace exact data lineage from source worker and immutable candidate through each reviewer attempt/receipt and, if present, into agent/role/tradeoff/component/outcome performance, assignment ranking, and evolver inputs. Prove missing joins with call-site/runtime evidence rather than absence by assumption.

Evaluate at least four representation options: restoring ordinary graph tasks; non-authoritative virtual task projections; a first-class review/evaluation graph node type separate from source tasks; and receipt/event-ledger records with dedicated UI/CLI projections. Compare lifecycle authority, retry/fencing, candidate binding, graph noise, scheduling isolation, auditability, accounting, messaging, replay, and evolvability. Address exactly-once learning projection, superseded candidates, semantic reject vs infrastructure failure, credit assignment to source composition versus reviewer, evaluator gaming/self-evolution, and migration of legacy histories. This is an audit/decision artifact only; do not change production behavior.

Use the charter's fractal structure and evidence labels. Integrate the live evidence that wg list --all exposes no FLIP/eval rows, 11/12 Done tasks have raw Pi usage but null graph accounting, all 12 have exact review receipts, agency stats reports zero evaluations, auto_assign=false, and modern completion/evaluation call sites do not invoke agency performance recording. Recheck each observation at task execution time.
