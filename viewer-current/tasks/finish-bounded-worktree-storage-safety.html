The second bounded-storage pass landed at 92465ba3/a4202c6c, but its bound FLIP review rejected four remaining correctness claims. Close them before service restart or production activation. Safety outranks deduplication: if sharing cannot be proven safe, use a private copy/empty layer.

  1. Command identity: controlled_cargo_command hashes the cargo tail but ignores stateful shell setup (export RUSTFLAGS=...; cargo build, cd other-dir; cargo build, CARGO_HOME=... cargo build, shell functions/subshells/redirections). Parse a deliberately tiny accepted grammar and fail closed to an attempt-isolated non-reusable namespace for everything else. Include working directory, CARGO_HOME, rustup/toolchain, target/profile/features/config/rustflags and all accepted env assignments. Arbitrary future worker cargo commands must never inherit an “exact” baseline prepared for a different command; limit reuse to a command identity WG can actually attest.

  2. Baseline immutability: remove writable hard-link cloning of Cargo target files. Prefer verified filesystem reflink/FICLONE (CoW), with private byte-copy or empty layer fallback. Never hardlink mutable build artifacts. Add an adversarial regression that truncates/overwrites/renames every file type in one worker layer and proves baseline plus sibling layer hashes/bytes/inodes remain unchanged.

  3. Rollback path replacement: UnpublishedCachePath::drop must not recursively remove merely by pathname plus boolean. Bind cleanup to a cryptographically random ownership marker and captured filesystem identity; re-open/revalidate immediately before removal and refuse on replacement. Tests must replace the path between creation and Drop with a pre-existing sentinel tree and prove it survives byte-identically while the genuine owned path is cleaned.

  4. Candidate provenance: candidate smoke must build the binary from the exact submitted HEAD, record source tree/commit plus binary digest in a candidate-build receipt, and invoke that exact path. Test must reject a stale binary copied into the expected path. Bind the smoke receipt into deterministic completion evidence.

Review adjacent use sites for hardlinks, rename races, marker spoofing, and arbitrary Cargo invocation assumptions. Do not install the binary globally or restart the service from this task; final activation happens only after review.
