Description

Convert ordinary completion/finalization blockers from terminal source failures into durable resumable states.

Current incident: provider-backoff-contract produced and pushed a clean immutable candidate, then strict review-attempt exhaustion called the generic wait path. Parking required exact live Pi session/process guards even though the model turn was already settled. A dirty attached integration checkout also refused publication. The wrapper ultimately recorded source_execution_failed/provider timeout. None of these conditions invalidated the source work.

Implement the narrow state-machine correction:

  • Strict model-review budget exhaustion must durably enter a typed NeedsReview/Waiting state, release the worker, and preserve the immutable candidate even when no live Pi continuation can be attested. Persist a session selector only when attested; settled/terminal source attempts must not need session continuity to wait safely.
  • A dirty attached integration checkout must never be reset or overwritten. Preserve the accepted candidate and transition to a typed LandingPending/Waiting state with an idempotent safe-next action. Resume landing after an explicit retry or authoritative checkout-clean event without rerunning source or model review.
  • Finalization blockers must not mutate the lifecycle to semantic/source Failed. Preserve exact task/generation/attempt/fence/candidate binding and all receipts across restart.
  • Keep the real safety invariants: exact reviewed commit, clean worker worktree, immutable review evidence, target-ref CAS, no unreviewed merge, and no reset --hard over user changes.
  • Expose actionable status/reason in wg show/status.

Validation

  • Unit test: review budget exhaustion with a settled Pi watchdog and unavailable exact guards enters Waiting/NeedsReview, clears assignment, and preserves candidate rather than returning a source failure.
  • Unit test: dirty attached main preserves user index/worktree bytes exactly and records LandingPending.
  • Restart test: the pending finalization state and exact candidate binding survive byte-for-byte and resume idempotently.
  • Test: cleaning the checkout or explicit resume lands once without source rerun or model re-review.
  • Test: stale candidate, moved target ref, or fence mismatch still fails closed.
