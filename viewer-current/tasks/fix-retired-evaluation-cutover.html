Description

Objective

Remove the impossible compatibility state where retired .assign-*, .flip-*, and .evaluate-* graph rows can still block live work even though the dispatcher refuses to run them.

Confirmed current contradiction:

  • query::is_eval_gate_pending blocks ordinary downstream work whenever .evaluate-<source> exists and is not Done;
  • service::coordinator::is_retired_agency_task refuses to dispatch that row;
  • priority promotion happens before the retired-row refusal, causing a promote/list/ignore loop every tick;
  • wg evaluate run/record writes a separate scored-evaluation store and cannot satisfy this obsolete graph-row gate;
  • the diagnostic says to migrate, but no supported migration exists.

Implement a versioned, explicit wg migrate evaluation-cutover [--dry-run] (or equally clear name) that preserves old rows/logs/verdicts as immutable historical evidence while removing their scheduling/dependency authority. Migrate legacy PendingEval/FailedPendingEval source states using exact completion/candidate evidence where possible; ambiguous cases must fail closed with one concrete candidate-bound operator action, never require rm-dep surgery or invent a pass. Back up graph bytes and make replay idempotent.

Filter retired rows before priority promotion/dispatch ordering and emit a bounded once-per-row diagnostic rather than per-tick spam. Make status/show explain the legacy condition and supported command. Clarify that ordinary manual/external quality scores do not satisfy exact candidate acceptance; provide a receipt-bound adjudication/recovery mechanism if migration cannot decide.

Validation

  • Add fixtures reproducing all three reported bugs: permanent retired evaluator blocker, promote-then-ignore tick loop, and unrelated scored evaluations failing to clear the obsolete gate.
  • Add migration tests for dry-run, backup, idempotence, exact-evidence conversion, ambiguous fail-closed handling, and preservation of every legacy row/log/verdict byte.
  • Add a terminal-level smoke scenario where a Done reviewed source has a stale .evaluate-* row and downstream work dispatches after the supported migration without rm-dep or graph editing. Register it in the grow-only smoke manifest with this task as owner.
  • Verify arbitrary wg evaluate record data cannot forge candidate acceptance, while the explicit candidate-bound operator mechanism is auditable.
  • Run the owned smoke scenario against the candidate binary, focused Rust tests, and cargo fmt --check.
  • Report changed files, migration output, preserved evidence, and residual risks.
