Description

Implement the recovery plan's separate exactly-once observation projection from accepted terminal outcomes into Agency learning. The completion/review plane must remain advisory and must not gain task lifecycle authority. Define one stable observation identity keyed by task generation/attempt plus immutable completion/publication receipt; project only verified terminal outcomes; make retries, daemon restarts, idempotent wg done, and operator reconciliation unable to double-count. Preserve attribution, route, model, usage/cost, review disagreement, and operator-accept provenance. Do not silently reinterpret completion FLIP/eval as Agency evaluation scores: map evidence explicitly, document unknown/unscored fields, and retain the existing manual wg evaluate surface. Add migration/backfill behavior that is bounded and idempotent.
