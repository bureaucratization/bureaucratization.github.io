wg-vizview-inside

WG VizView inside pi: an embedded, clickable live work-graph panel in the wg-pi plugin. Motivation: our nearest analogue (pi-process plugins) shows ephemeral process state; WG's graph is durable — tasks, receipts, review lanes, attempt history backed by the daemon and immutable evidence. An embedded VizView makes that durability visible inside the pi session itself. Scope (first slice): (1) a pi extension command (e.g. /wg-viz) plus optional persistent widget (ctx.ui.setWidget: one-line summary — in-progress/ready/blocked counts from the daemon) using ctx.ui.custom() to render the live graph inside pi's TUI; (2) data from the existing daemon socket (the same client protocol the TUI uses) with a bounded poll/debounce; fallback to design-retire-the
